# Blog-Platform-With-Comments
# Project Overview

This project is a simple Blog Platform developed using Flask and SQLite. It allows users to register, log in, create blog posts, edit or delete their own posts, and interact through comments. The application demonstrates the implementation of user authentication, CRUD operations, database integration, and user interaction features in a full-stack web application.

# Features
* User Registration and Login Authentication
* Create, Read, Update, and Delete (CRUD) Blog Posts
* Comment System for User Interaction
* Session Management using Flask-Login
* SQLite Database Integration
* Responsive User Interface using Bootstrap
* Secure Access to Authorized Features
# Technologies Used
* Python
* Flask
* Flask-SQLAlchemy
* Flask-Login
* SQLite
* HTML5
* CSS3
* Bootstrap
